# breast-cancer-diagnosis
Previsão do diagnóstico de câncer de mama em Wisconsin, Estados Unidos

## Passos iniciais 

1. Baixar o repositório
2. Ir na pastas `utils` e rodar o arquivo `criar_dataframe.R`
3. Verificar na pasta `database` se foi criado o arquivo `breast-cancer.csv`

## Rodando o projeto

Caso queira rodar SOMENTE o treinamento do modelo junto com a previsão, é só rodar a `main.R` inteira.
